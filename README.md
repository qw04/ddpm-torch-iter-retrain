# Iterative Retraining of Diffusion Models

What happens when generative models are repeatedly retrained on data generated by earlier models? Across 10 retraining rounds, DDPMs showed no single pattern: depending on the dataset, they diverged, collapsed to a single mode, or stayed relatively stable. URSS research at the University of Warwick, run on a Slurm HPC cluster and presented at the Warwick URSS Showcase.

## Results

| Divergence (gaussian8) | Mode collapse (creditcard) | Relatively stable (poisson_glm) |
| --- | --- | --- |
| ![Wasserstein distance rising across retraining rounds](plots/single_model_fixed-large_gaussian8_wasser.png) | ![Recall falling to zero across retraining rounds](plots/single_model_fixed-large_creditcard_recall.png) | ![Recall staying high across retraining rounds](plots/single_model_fixed-large_poisson_glm_recall.png) |
| Wasserstein distance climbs from ~1.2 to ~5.0 | Recall falls to 0 after the first round | Recall stays between ~0.89 and 1.00 |

**Also tested:** mitigation strategies against this drift: accumulating data across rounds, curating the synthetic data, and varying model size.

**Companion repo:** the same experiment on [Conditional Flow Matching](https://github.com/qw04/conditional-flow-matching-iter-retrain).

**Tech:** Python, PyTorch, Slurm

## What this project investigates

This project investigates the degradation and distributional drift that occurs when machine learning models are iteratively retrained on synthetic data generated by previous models.

## Experiment Overview

Each experiment follows a modular pipeline:

1. Generate or load synthetic datasets
2. Iteratively retrain models on synthetic data
3. Apply mitigation strategies (curation, accumulation, model scaling)
4. Evaluate performance and distributional changes
5. Visualise results via plots and generated images

## Assumptions & Configuration

- Python ≥ 3.x
- Required dependencies are listed in `requirements.txt`
- Dataset paths and output directories are defined within individual scripts
- Experiments may be computationally expensive depending on model size


## Outputs

Depending on the experiment, scripts may produce:
- Saved plots (`.png`, `.pdf`)
- Generated image samples
- Logged metrics across retraining iterations

Outputs are written to experiment-specific directories.


## Motivation

As synthetic data becomes increasingly common, models are often trained on data generated by previous models. Understanding and 
mitigating the long-term effects of this feedback loop is critical for reliable deployment of generative systems.
